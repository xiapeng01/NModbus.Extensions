## 全项目代码走查（无修改，仅产出报告）
- 产出 `PROJECT-REVIEW.md`，36 条问题分五类（严重/中等/卫生/CI/文档）。
- 最高优先级结论：
  1. `EnumEndian` 枚举值 0 是 DCBA 而非文档默认 CDAB，`default(EnumEndian)` 会静默拿到错误字节序。
  2. `ConvertEndian<T>` 的 XML 注释把 4 字节的高低标反（注释说 d 最高，实际 a 最低），代码本身正确。
  3. 字符串通道无条件 Swap 每个寄存器、忽略 SetEndian，与 16 位数值通道规则冲突。
  4. `ToInt32/ToUInt32/ToFloat` 对奇数长度寄存器数组会因 BlockCopy 越界抛 .NET 内部异常（注释说"被忽略"，与实际不符）。
  5. `Marshal.SizeOf<T>()` + `MemoryMarshal.Cast` 对非 blittable 泛型 T 未定义行为，应改 `Unsafe.SizeOf<T>()` 并做白名单。
  6. `p16` / `pByte` 两个 static MemoryPool 字段零引用；`FormTargetEndian` 三个别名与 `ToTargetEndian` 完全重复。
  7. Demo 未引用 HslCommunication，README 声称的"互读对照"不存在。
- 本地 `dotnet build` 失败原因：代理 127.0.0.1:51517 隧道 502，无法访问 nuget.org（NU1301），属环境问题非代码问题。
- git 仓库存在 dubious ownership（目录属主 SID 与当前用户不符），git 命令需先 `safe.directory` 配置才能用。
